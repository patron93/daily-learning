# Инструкция для ежедневного запуска

Этот файл читает Claude при каждом запуске запланированной задачи (каждый день в 20:00 по Варшаве).
Всё поведение настраивается здесь, поэтому, чтобы что-то поменять, достаточно отредактировать этот файл.

## Шаги

1. Прочитай `profile.md`, `feedback.md`, `state.json`, `templates/lesson.md`, а также последние 3 урока в `lessons/`, чтобы не повторяться по стилю и темам.
2. **Польский**:
   - Открой `polish/vocabulary.json`. Повторение: выбери до 5 слов, у которых `next_review <= сегодня` (сначала самые просроченные).
   - Новые слова: добавь 5 новых слов уровня A1–A2. Их не должно быть в `vocabulary.json` (проверь поле `pl`, учитывая разные формы). Слова желательно связать одной темой дня: еда, транспорт, работа, urząd, врач, магазин, IT-офис и т.д.
   - Главный блок дня берётся по ротации из `state.json → polish_rotation`: `grammar` → `words_deep` → `grammar` → `fact`.
     - `grammar`: возьми следующий непройденный пункт из `polish/grammar.md` (первый с `[ ]`), объясни его просто, на русском, с 3–4 примерами и сравнением с русским или белорусским, если это помогает. Отметь пункт `[x]` с датой.
     - `words_deep`: разбор группы слов: ложные друзья переводчика (например, «uroda», «zapomnieć», «dywan»), устойчивые выражения или разговорные фразы.
     - `fact`: интересный факт о языке или культуре Польши, связанный с языком.
   - Мини-упражнение: 3 задания (перевод или вставка формы), ответы в конце письма под заголовком «Ответы».
3. **Профразвитие** (тимлид, Angular-фронтенд, плюс бэкенд и AI):
   - Ротация по `state.json → tech_rotation`: `angular` → `leadership` → `news` → `architecture` → `ai` → `backend` → `classic`.
   - `news`: сделай веб-поиск свежих новостей за последнюю неделю (Angular, TypeScript, web platform, AI-инструменты для разработчиков). Выбери одну самую полезную новость и дай ссылку на источник.
   - Для остальных категорий возьми первую подходящую неотмеченную тему из `tech/topics.md`. Можно и свою, если она лучше, но её не должно быть в разделе «Пройдено».
   - Формат: что это (2–3 абзаца), зачем это тимлиду, пример кода, если уместен, «как применить завтра в команде» (1–2 пункта), ссылка для углубления. Проверяй факты веб-поиском, если тема касается версий или API.
   - Добавь тему в раздел «Пройдено» в `tech/topics.md` с датой.
4. Собери урок по `templates/lesson.md` и сохрани его в `lessons/YYYY-MM-DD.md`.
5. Обнови `polish/vocabulary.json`:
   - новые слова: `box: 1`, `added: сегодня`, `next_review: сегодня + 1 день`;
   - повторённые слова: `box += 1` (максимум 5), `next_review = сегодня + интервал[box]`, где интервалы такие: 1→1, 2→3, 3→7, 4→14, 5→30 дней. `reviews += 1`.
6. Обнови `state.json`: `day += 1`, `last_run`, сдвинь обе ротации на следующий элемент.
7. Сделай commit и push в `main` с сообщением `lesson: YYYY-MM-DD`.
8. Доставка:
   - Отправь урок письмом через Gmail на адрес из `profile.md` с темой `📚 День N: <тема польского> · <тема tech>`. Тело письма — урок целиком.
   - Отправь короткое сообщение в чат (SendUserMessage) с заголовками обеих тем и 5 новыми словами, чтобы оно пришло push-уведомлением.

## Правила

- Язык объяснений русский. Польские примеры всегда с переводом. Для новых слов указывай род (m/ż/n) и, если слово неочевидное, ударение или подсказку по произношению.
- Объём: чтение на 7–10 минут.
- Если пользователь оставил отзыв в `feedback.md`, учти его и не удаляй.
- Если Gmail недоступен, всё равно сохрани урок и сделай push; в сообщении укажи, что письмо не ушло.
- Никогда не удаляй историю; только дописывай.
