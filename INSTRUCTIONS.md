# Инструкция для ежедневного запуска

Этот файл Claude читает при каждом запуске запланированной задачи.
Всё поведение настраивается здесь: чтобы что-то поменять, достаточно отредактировать этот файл.

Урок приходит в два захода, с разницей примерно 8 минут:

| Трек | Задача | Время (Варшава) |
|---|---|---|
| `polish` | Daily learning: польский | 19:53 |
| `tech` | Daily learning: профразвитие | 20:01 |

В промпте каждой задачи указан её трек. Выполняй **только** шаги своего трека и общие шаги.

## Общие шаги (оба трека)

1. `git pull` в `main`. Прочитай `profile.md`, `feedback.md`, `state.json` и шаблон своего трека: `templates/polish.md` или `templates/tech.md`. Посмотри последние 3 урока своего трека в `lessons/`, чтобы не повторяться по стилю и темам.
2. **Номер дня N.** Если `state.last_run` равен сегодняшней дате, то N = `state.day` (другой трек уже начал день). Иначе N = `state.day + 1`; запиши `day = N` и `last_run = сегодня`.
3. **Защита от дубля.** Если `state.<трек>_last_run` уже равен сегодняшней дате и файл урока трека за сегодня существует, ничего не создавай и не перезаписывай. Просто пришли в чат короткое сообщение, что урок уже был, и закончи.

## Трек `polish`

1. Открой `polish/vocabulary.json`. Повторение: выбери до 5 слов, у которых `next_review <= сегодня` (сначала самые просроченные).
2. Новые слова: добавь 5 новых слов уровня A1–A2. Их не должно быть в `vocabulary.json` (проверь поле `pl`, учитывая разные формы). Слова желательно связать одной темой дня: еда, транспорт, работа, urząd, врач, магазин, IT-офис и т.д.
3. Главный блок дня берётся по ротации из `state.json → polish_rotation`: `grammar` → `words_deep` → `grammar` → `fact`.
   - `grammar`: возьми следующий непройденный пункт из `polish/grammar.md` (первый с `[ ]`), объясни его просто, на русском, с 3–4 примерами и сравнением с русским или белорусским, если это помогает. Отметь пункт `[x] (YYYY-MM-DD)`.
   - `words_deep`: разбор группы слов: ложные друзья переводчика (например, «uroda», «zapomnieć», «dywan»), устойчивые выражения или разговорные фразы.
   - `fact`: интересный факт о языке или культуре Польши, связанный с языком.
4. Мини-упражнение: 3 задания (перевод или вставка формы), ответы в конце письма под заголовком «Ответы».
5. Собери урок по `templates/polish.md` и сохрани в `lessons/YYYY-MM-DD-polish.md`.
6. Обнови `polish/vocabulary.json`:
   - новые слова: `box: 1`, `added: сегодня`, `next_review: сегодня + 1 день`;
   - повторённые слова: `box += 1` (максимум 5), `next_review = сегодня + интервал[box]`, где интервалы такие: 1→1, 2→3, 3→7, 4→14, 5→30 дней. `reviews += 1`.
7. В `state.json`: `polish_last_run = сегодня`, сдвинь `polish_rotation.next_index` на следующий элемент (по кругу).
8. Commit и push в `main` с сообщением `lesson: YYYY-MM-DD polish` (перед push сделай `git pull --rebase`).
9. Доставка:
   - Письмо через Gmail на адрес из `profile.md`, тема `📚 День N · 🇵🇱 <тема польского>`, тело — урок целиком (HTML).
   - Короткое сообщение в чат (SendUserMessage): номер дня, тема польского и 5 новых слов с переводом.

## Трек `tech`

1. Профразвитие (тимлид, Angular-фронтенд, плюс бэкенд и AI). Ротация по `state.json → tech_rotation`: `angular` → `leadership` → `news` → `architecture` → `ai` → `backend` → `classic`.
   - `news`: сделай веб-поиск свежих новостей за последнюю неделю (Angular, TypeScript, web platform, AI-инструменты для разработчиков). Выбери одну самую полезную новость и дай ссылку на источник.
   - Для остальных категорий возьми первую подходящую неотмеченную тему из `tech/topics.md`. Можно и свою, если она лучше, но её не должно быть в разделе «Пройдено».
   - Формат: что это (2–3 абзаца), зачем это тимлиду, пример кода, если уместен, «как применить завтра в команде» (1–2 пункта), ссылка для углубления. Проверяй факты веб-поиском, если тема касается версий или API.
2. Отметь тему `[x]` и добавь её в раздел «Пройдено» в `tech/topics.md` с датой.
3. Собери урок по `templates/tech.md` и сохрани в `lessons/YYYY-MM-DD-tech.md`.
4. В `state.json`: `tech_last_run = сегодня`, сдвинь `tech_rotation.next_index` на следующий элемент (по кругу).
5. Commit и push в `main` с сообщением `lesson: YYYY-MM-DD tech` (перед push сделай `git pull --rebase`).
6. Доставка:
   - Письмо через Gmail на адрес из `profile.md`, тема `📚 День N · 💻 <тема tech>`, тело — урок целиком (HTML).
   - Короткое сообщение в чат (SendUserMessage): номер дня, категория и тема, одна фраза о сути.

## Правила

- Язык объяснений русский. Польские примеры всегда с переводом. Для новых слов указывай род (m/ż/n) и, если слово неочевидное, ударение или подсказку по произношению.
- Объём: каждый трек читается за 4–6 минут.
- Если пользователь оставил отзыв в `feedback.md`, учти его и не удаляй.
- Если Gmail недоступен, всё равно сохрани урок и сделай push; в сообщении укажи, что письмо не ушло.
- Никогда не удаляй историю; только дописывай. Старые уроки (`lessons/YYYY-MM-DD.md`, до разделения) не трогай.
