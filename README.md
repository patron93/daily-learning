# daily-learning

🌐 Сайт с уроками: https://patron93.github.io/daily-learning/

Ежедневная «обучалка» на двух треках: **профразвитие** (тимлид Angular, архитектура, бэкенд, AI) и **польский** (A1 → A2 → B1).
Урок приходит каждый день в два захода: польский в 19:53, профразвитие в 20:01 (по Варшаве), каждый отдельным письмом и push-уведомлением в Claude.

Каждый новый урок заканчивается интерактивным квизом (сегодняшняя тема и повторение прошлых). Отдельная страница «Тренажёр» даёт бесконечную практику по всем урокам и словам.

## Как устроено
| Файл | Что внутри |
|---|---|
| `INSTRUCTIONS.md` | Алгоритм ежедневного запуска. Меняешь его — меняется поведение |
| `profile.md` | Кто учится, уровень, интересы |
| `state.json` | Номер дня и ротация тем |
| `polish/vocabulary.json` | Все выученные слова с интервальным повторением (1 → 3 → 7 → 14 → 30 дней) |
| `polish/grammar.md` | План грамматики с отметками о пройденном |
| `tech/topics.md` | Бэклог тем и список пройденных |
| `lessons/` | Архив всех уроков |
| `lessons/*.quiz.json` | Вопросы квиза к уроку (пишет ежедневная задача вместе с уроком) |
| `templates/polish.md`, `templates/tech.md` | Формат уроков по трекам (`lesson.md` — старый общий формат, до разделения) |
| `trainer.md` | Страница «Тренажёр» |
| `.vitepress/theme/` | Тема сайта и компоненты квиза |
| `.vitepress/quiz/` | Логика квиза без Vue: выбор вопросов, проверка ответов |
| `tests/` | Тесты vitest (`npm test`) |
| `feedback.md` | Пожелания, которые учитываются в следующих уроках |

## Как управлять
- Хочешь тему: допиши её в `tech/topics.md`.
- Слово уже знаешь или хочешь повторить: поправь его `box` или `next_review` в `vocabulary.json`.
- Общие пожелания по формату или сложности пиши в `feedback.md`.
- Локальный запуск сайта: `npm install && npm run dev`.
- Тесты (логика квиза и проверка файлов квизов): `npm test`. В CI они идут перед сборкой, и упавший тест не даёт опубликовать сайт.
