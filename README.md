# daily-learning

Ежедневная «обучалка» на двух треках: **профразвитие** (тимлид Angular, архитектура, бэкенд, AI) и **польский** (A1 → A2 → B1).
Урок приходит каждый день в 20:00 письмом и push-уведомлением в Claude.

## Как устроено
| Файл | Что внутри |
|---|---|
| `INSTRUCTIONS.md` | Алгоритм ежедневного запуска. Меняешь его — меняется поведение |
| `profile.md` | Кто учится, уровень, интересы |
| `state.json` | Номер дня и ротация тем |
| `polish/vocabulary.json` | Все выученные слова с интервальным повторением (1 → 3 → 7 → 14 → 30 дней) |
| `polish/grammar.md` | План грамматики с отметками о пройденном |
| `tech/topics.md` | Бэклог тем и список пройденных |
| `lessons/` | Архив всех уроков |
| `templates/lesson.md` | Формат урока |
| `feedback.md` | Пожелания, которые учитываются в следующих уроках |

## Как управлять
- Хочешь тему: допиши её в `tech/topics.md`.
- Слово уже знаешь или хочешь повторить: поправь его `box` или `next_review` в `vocabulary.json`.
- Общие пожелания по формату или сложности пиши в `feedback.md`.
